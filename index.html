01 — THE PRINCIPLES

Trust is a boundary,
not a feeling.

Three decisions make the difference between a resilient interface and an avoidable risk.

01 /

Keep text as text.

Use safe output APIs, such as textContent, for untrusted plain text. Never treat it as executable markup.

02 /

Respect the context.

HTML, attributes, URLs, scripts, and CSS need different defenses. A single blanket escape rule cannot cover every context.

03 /

Layer your safeguards.

Use context-aware encoding, safe DOM APIs, validated destinations, vetted sanitization for rich HTML, and a restrictive CSP.

Render text, not markup.

For plain text in the DOM, use textContent or an equivalent safe API. Untrusted input is displayed without becoming HTML.

Rule: never route plain text through an HTML parser.

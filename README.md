# Context Matters — XSS Defense Studio

An offline browser learning experience showing safe plain-text DOM rendering,
output contexts, a non-navigating URL-policy exercise, and a knowledge check.

Open index.html in a browser. No login, external dependency, telemetry,
third-party resources, network calls, or live attack targets are required.
This is defensive education, not a penetration test or security audit.

Run tests with Node.js 20 or later: npm test
SHA256SUMS records the reviewed source bytes.

Public defensive education edition; not a security audit or exploit kit.
